# Stone Paper Scissors

A simple Python implementation of the classic Stone Paper Scissors game.

## 🎮 Features

* Player vs computer gameplay
* Random computer choices
* Win, lose, and draw conditions
* Simple command-line interface

## 🛠️ Built With

* Python

## ▶️ How to Run

```bash
python main.py
```

## 🎯 Purpose

This project was created to practice Python fundamentals, conditional logic, user input, and random number generation.
